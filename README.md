# Suivi Séniors 2026-2027 – Métro Foot Antony

Application de suivi de l'équipe séniors (District 92, D5 poule B) :

- feuille de présence des entraînements (mardi, jeudi) et des matchs ;
- présences par match : présent, absent, excusé, blessé, avec motif ;
- calendrier, scores, buteurs, passeurs, cartons, homme du match ;
- résumé du match, points forts et points faibles, conseils de progression ;
- classement de la saison et fiche de chaque joueur.

## Où l'utiliser

L'application tourne sur claude.ai : https://claude.ai/artifact/EASxsrrtcoihA77z3okwxF

Les données (joueurs, matchs, présences) sont stockées dans la base partagée de cette page.
Ouvert en dehors de claude.ai, `index.html` s'affiche mais reste hors ligne : rien n'est enregistré ni partagé.

## Fichiers

- `index.html` : toute l'application (HTML, CSS et JavaScript dans un seul fichier).
